# Farkle

Базовый проект на Unity 6000.3 для четырёх площадок: Яндекс Игры, Игры ВКонтакте, VK Play и RuStore.
Цель: довести интеграцию всех площадок до рабочего состояния один раз и начинать с этого проекта
каждую новую игру, не переписывая работу с SDK под каждую. Фаркл станет первой игрой на этой основе,
но правила и логика игры сейчас не в работе.
Структура проекта, стек и правила: [AGENTS.md](AGENTS.md).

## Где мы сейчас

Состояние на 11 сентября 2026 года.

Готов скелет платформы. Игрового кода нет и сейчас не планируется: вместо игры
тестовая сцена `Scenes/PlatformTest.unity` с кнопкой на каждый метод платформенных интерфейсов.

**Яндекс Игры: закрыто.** На живом черновике подтверждено:

- Сборка загружается и запускается, панель отрисована полностью, тексты на русском.
- На debug-панели индикатор лоадера `IT` зелёный, индикатор языка 文 зелёный.
- Автоопределение языка работает: SDK отдаёт `ru`, интерфейс переключается с английского на русский.
- Работают: статус, авторизация, сигналы `LoadingAPI.ready` и `GameplayAPI.start/stop`,
  реклама обоих видов, сохранение и загрузка, лидерборд `score`.
- Покупки отложены до этапа монетизации, товар `no_ads` не заведён.

**Игры ВКонтакте: работает на ПК и в мобильном приложении VK.** Игра «Зонк: Кости Фортуны», ID 54765957,
хостинг VK, пока включена только для администраторов. Мост на VK Bridge 3.0.2.
Проверено: инициализация, язык из SDK, тип устройства, авторизация и имя игрока, выбор качества,
сохранение и загрузка через хранилище VK, тестовая реклама в мобильном приложении VK. На vk.com с ПК
VK отвечает на рекламу `no ads (20)`, игра это корректно обрабатывает.
Выкладка из Unity: `Farkle/Build/VK Games + Deploy (dev)`. Лидерборды и покупки на VK требуют своего сервера,
поэтому сейчас недоступны. Не доделано: размер окна на ПК (было 411×731), ориентация на телефоне.

**Качество графики: каркас.** Площадка сообщает тип устройства, `IQualityService` выбирает уровень
Low/Medium/High и включает Quality Level Unity: ПК получает `PC`, телефоны и планшеты `Mobile`.
Сами уровни ещё не настраивались, это те, что пришли с шаблоном URP.

**RuStore: Android-сборка работает, демо-реклама обоих видов показывается.** Яндекс Реклама 8.4.0, демо-блоки.
Сохранения локальные, лидерборда и покупок нет (см. «Особенности RuStore» в AGENTS.md).

**VK Play:** реализации-заглушки с TODO, SDK не подключён.

## С чего продолжить

### Следующий запуск: финальная проверка базового проекта

Решение от 11 сентября: после этой проверки базовый проект считается закрытым, дальше начинается игра.
Все сборки делаются заново, потому что после последних проверок менялись сжатие, сборка, реклама и настройки проекта.

**1. Собрать заново все три площадки** (VK Play пока заглушка, её не собираем):

| Площадка | Как собрать и выложить | Где проверять |
|---|---|---|
| Яндекс Игры | `Farkle/Build/Yandex Games (WebGL)`, запаковать содержимое `Builds/Yandex` в zip, загрузить в черновик в Консоли | Консоль → «Открыть с debug-панелью» |
| Игры ВКонтакте | `Farkle/Build/VK Games + Deploy (dev)`: собирает и выкладывает сам, в конце кнопка «Открыть игру» | `vk.com/app54765957` на ПК и в приложении VK на телефоне (ссылку открывать через «Избранное» VK, не через Telegram) |
| RuStore | `Farkle/Build/RuStore (Android APK)`, установить `Builds/RuStore/Farkle.apk` | телефон или эмулятор |

**2. На каждой площадке пройти панель** (подождать 10 секунд после запуска, чтобы загрузилась реклама):

| Кнопка | Что должно быть |
|---|---|
| Статус | `initialized=True`, `sdkLang=ru`, `uiLang=ru`, строка качества с правильным `device` (ПК → `PC`, телефон → `Mobile`) |
| Показать interstitial | реклама показалась, в логе «Реклама открыта» и «закрыта», `shown=True` |
| Показать rewarded | досмотреть до конца, `result=Rewarded` |
| Сохранить → Загрузить | загружено то же, что сохранено |
| Лидерборд: отправить / топ / моя запись | только Яндекс (на VK и RuStore недоступен, `leaderboard=False` — это норма) |
| Сменить язык, Сменить качество | подписи и `level` меняются |
| Яндекс: debug-панель | индикаторы `IT` и 文 зелёные |

Если реклама на RuStore отвечает `NotAvailable`, смотреть в логе панели строки `[RuStore] … failed to load`.

**3. Если всё прошло:** закоммитить и поставить в git метку, например `template-v1`. С этой точки начинаются новые игры.
Если что-то не прошло, чинить до метки.

### После закрытия базы: игра

Фаркл (кости): правила в `Farkle.Core` (чистый C#, покрываются тестами без редактора), затем сцены и UI в `Farkle.Game`.
Тестовая сцена `PlatformTest` остаётся как инструмент проверки площадок.

### Отложено (не блокирует игру)

- **VK Play:** нужен доступ к кабинету разработчика и документации API браузерных игр. При подключении вынести
  общую механику мостов Яндекса и VK в отдельную сборку.
- **Сервер игры:** лидерборды на VK и RuStore, покупки на VK. Покупки на всех площадках — на этапе монетизации.
- **RuStore:** свои рекламные блоки в Рекламной сети Яндекса (`RuStoreAdUnits`), ключ подписи APK, карточка в консоли;
  облачное сохранение через GameCenter и платежи требуют ИП или юрлица.
- **VK:** размер окна на ПК (было 411×731: «Отображение» → широкоформатный режим и iframe 1000×700), ориентация
  на телефоне под игру, что приходит при закрытии rewarded раньше времени.
- **Качество:** настроить уровни в Project Settings > Quality (ужатие текстур и render scale на `Mobile`, при необходимости
  уровень `Medium` для планшетов), разрешение канваса в WebGL на телефонах с высоким devicePixelRatio.
- **Шаблон для следующих игр:** имя `Farkle` зашито в пространства имён, asmdef, меню и define `FARKLE_*`.
  Решить, делать нейтральный префикс или автоматизировать переименование, когда начнётся вторая игра.
  Идентичность проекта (компания, название, пакет) уже в одном месте: `Editor/ProjectIdentity.cs`.

Мелкие хвосты, которые можно закрыть в любой момент:

- Удалить остатки шаблона Unity: `Assets/TutorialInfo`, `Assets/Readme.asset`, `Assets/Scenes/SampleScene.unity`.
- Удалить дубликат решения `Far.sln`.
- Определиться с уровнем Managed Stripping Level. Сейчас стоял High, для отладки предлагалось Minimal.
  Возвращаться к High имеет смысл только ради размера билда и только с проверкой в браузере.
- Папка `Test/` со скриншотами попала в коммит `YandexCompleted`. Если она не нужна в истории,
  убрать её из git и добавить в `.gitignore`.
